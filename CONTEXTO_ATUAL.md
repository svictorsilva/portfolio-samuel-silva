## 8. Próxima tarefa — Aula 06.4

**Arquivo:** `src/App.css`

Primeiro, ajustar o seletor `.intro h1`:

```css
.intro h1 {
  font-family: var(--font-heading);
  font-size: clamp(48px, 8vw, 88px);
  font-weight: 800;
  letter-spacing: -4px;
  line-height: 1.05;
}
```

Explicações:
- `font-family`: família tipográfica.
- `font-size`: tamanho do texto.
- `clamp()`: tamanho responsivo com limites.
- `font-weight`: espessura da fonte.
- `letter-spacing`: espaço entre letras.
- `line-height`: altura das linhas.
